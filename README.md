# Hi, I'm Eftekhar Azahar

**Cloud PaaS Engineer · Cloud Managed Services · ITSM & SLA Management**
Dhaka, Bangladesh

I'm on the Cloud Managed Services team for a telecom operator's new private cloud on Huawei Cloud Stack, which is taking over the operator's running applications. My part: building SLA measurement and reporting for PaaS and iPaaS services, preparing L1 operations SOPs, and provisioning cloud environments (ECS, security groups, golden images).

Before that I spent nearly three years at **Wipro**, supporting **Grameenphone**'s 24×7 production systems. I started in billing operations (BSS), then moved to ITSM / NOC operations, where I designed the escalation matrix workflow and the SLA and incident report forms.

**Day to day:** incident, service request and change request management · SLA design and reporting · MTTR / MTBF · RCA and CAPA tracking · SQL / PostgreSQL · Linux and Bash
